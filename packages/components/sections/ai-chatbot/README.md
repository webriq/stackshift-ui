# @stackshift-ui/ai-chatbot

A customizable AI chatbot package for building intelligent conversational interfaces in web/mobile apps

Please refer to the [documentation](https://stackshift-ui.webriq.com/docs/components/ai-chatbot) for more information.

## Installation

```sh
yarn add @stackshift-ui/ai-chatbot
# or
npm i @stackshift-ui/ai-chatbot
```
